Complete self-hosted media infrastructure running on a Synology NAS, orchestrated through Docker Compose. The stack includes a media server for streaming, automated content organization that sorts and renames files on arrival, health monitoring for all services, and secure remote access via reverse proxy. Designed as a single `docker-compose.yml` deployment  - one command brings up the entire stack with proper networking, volume mounts, and restart policies.
