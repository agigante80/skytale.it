A Python pipeline that automates the full blog content lifecycle  - from topic research and outline generation through writing, formatting, and publishing to Jekyll-based static sites. Uses the OpenAI API with structured prompts to produce technically accurate articles, then handles image generation, markdown formatting, and git-based publishing. Powers both galena.es and ondahertz.es as the upstream content engine.
